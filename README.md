- 📦 **Modrinth Integration** - Browse, search, and install mods, resource packs, and shaders directly from Modrinth with one click!

## 📦 The `FL PACK` System (.flpack)

![FL Pack System](https://i.ibb.co/0y6knNV9/FLPACKBG.png)

Fluent Launcher introduces a revolutionary new way to share modpacks: **FL Pack (`.flpack`)**.

### What is it?
An `.flpack` is a highly compressed, proprietary modpack format designed specifically for Fluent Launcher. It allows you to share your entire modded setup—including mods, configs, resource packs, and shaders—in a single, lightweight file.

### How does it work?
- **Exporting**: Go to your instance settings and click "Export FLPack". The launcher automatically gathers all necessary files, serializes the metadata, and compresses everything into a single `.flpack` file.
- **Importing**: Simply double-click an `.flpack` file anywhere on your computer! Fluent Launcher automatically associates with the `.flpack` extension in Windows. It will launch, unpack the instance, install the correct Minecraft version and modloader, and have you ready to play in seconds.
- **Smart Compression**: It packs the files you specifically choose, keeping the file size minimal and easily shareable.
